# 🚀 TaskFlow Lite

### Your Client-Side Task Management Solution

TaskFlow Lite is a fully functional task manager application built using **Vanilla JavaScript**.  
It runs completely in the browser and uses **localStorage** for data persistence.

---

## 📌 Project Overview

TaskFlow Lite allows users to create, manage, update, and delete tasks easily.

The application focuses on:

- CRUD Operations
- DOM Manipulation
- Event Handling
- Form Validation
- Local Storage
- Responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

---

## ✨ Features

### ✅ Task Management

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks permanently


### ✅ Data Persistence

- Tasks are stored using localStorage
- Data remains available after browser refresh


### ✅ Task Filtering

Users can filter tasks:

- All Tasks
- Active Tasks
- Completed Tasks


### ✅ Validation

- Prevents empty task submission
- Character length validation
- Error feedback messages


### ✅ Responsive Design

- Mobile friendly layout
- Clean user interface

## 🏗️ Application Architecture

The project follows an MVC-like structure:

### Model

Handles task data and localStorage.

### View

Responsible for displaying tasks dynamically.

### Controller

Handles user actions and application logic.
